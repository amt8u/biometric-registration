Deployment notes:
• Drive folder and tracking spreadsheet are NOT created automatically. Create them manually and paste their IDs above (or set DRIVE_ROOT_ID / SHEET_ID in Script Properties).
• The script will create the required tabs (Registrations, Family Members, Deletion Log) inside the spreadsheet you provide, if they don't already exist.
• To embed in Google Sites: deploy as Web App (Execute as: Me, Access: Anyone in workspace), then Insert → Embed → URL and paste the web-app URL.
• All document uploads and emails happen under the deploying owner’s Google account — no end-user OAuth required.
